# Release Notes

Markdown you can **read** while you edit it — the syntax stays in the document,
styled instead of hidden.

## Highlights

- Headings, emphasis and links styled in place
- GitHub alerts rendered as callouts
- Table of contents built from the document
- Diff against git `HEAD` without leaving the editor

> [!NOTE]
> Every character you see is real markdown. Nothing is rewritten behind your back.

## Getting Started

1. Open any `.md` file
2. Run **Open with Markdown Beautiful Editor**
3. Start typing

```bash
code --install-extension chrp.markdown-beautiful-editor
```

## Supported Syntax

| Feature      | Status | Notes                       |
|--------------|:------:|-----------------------------|
| Tables       |   Yes  | Column widths align live    |
| Task lists   |   Yes  | `- [ ]` and `- [x]`         |
| Footnotes    |   Yes  | Rendered as superscripts    |
